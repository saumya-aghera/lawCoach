# ⚖️ AI LawAIer

Real-time AI legal rights coaching — listens to encounters, scans legal documents,
and generates post-encounter PDF reports. Powered by **Google Gemini via Vertex AI**.

---

## Features

| Feature | Description |
|---------|-------------|
| 🎤 Live Coaching | Microphone listens to the encounter; AI suggests your rights in real-time |
| 📷 Document Scanner | Camera or file upload → AI reads warrants, tickets, IDs instantly |
| 🎥 Video Analysis | Upload dashcam / CCTV footage → timeline, rights violations, evidence rating |
| 📄 PDF Report | Post-encounter professional report for your attorney |
| ⚖️ Lawyer Finder | Matched attorneys by situation and state |
| 🗄️ RAG Law DB | ChromaDB vector store of 25 law chunks across 5 situations + 4 states |

---

## Architecture

```
laws_data.json ──→ ChromaDB (pre-built vector store)
                        │
Browser mic ──→ /analyze ──→ RAG query + Gemini → {urgency, suggestion, law}
Camera/file ──→ /analyze-document ──→ Gemini Vision → document analysis + DMV points
Video upload ──→ /analyze-video    ──→ Gemini Vision → timeline + violations
Session end ──→ /generate-report   ──→ Gemini + ReportLab → PDF download
```

**Stack:** FastAPI · ChromaDB · google-genai (Vertex AI) · React/Vite · Nginx · Cloud Run

## Option A — Run Locally

### Prerequisites
- Python 3.11+, Node 20+, `uv` (installed automatically by script)
- Google Cloud SDK: [install](https://cloud.google.com/sdk/docs/install)
- A GCP project with Vertex AI enabled

### Steps

```bash
# 1. Authenticate with GCP
gcloud auth application-default login
gcloud config set project YOUR_PROJECT_ID

# 2. Start everything (backend + frontend)
cd lawCoach
chmod +x scripts/start_local.sh
./scripts/start_local.sh
```

The script will:
- Install Python deps via `uv`
- Build ChromaDB on first run (downloads embedding model ~90MB)
- Install frontend npm packages
- Start backend on **http://localhost:8000**
- Start frontend on **http://localhost:3000**

**Access the app:** http://localhost:3000

## Option B — Deploy to Google Cloud Run

### Step 1 — One-time GCP setup (run once per project)

```bash
cd lawCoach
chmod +x scripts/setup.sh
./scripts/setup.sh
```

This enables all required APIs, creates service account `lawaier-sa` with correct
IAM roles, creates Artifact Registry repo `lawaier`, and writes `set_env.sh`.

**APIs enabled:**
- `compute.googleapis.com`
- `cloudresourcemanager.googleapis.com`
- `aiplatform.googleapis.com` (Vertex AI / Gemini)
- `run.googleapis.com`
- `cloudbuild.googleapis.com`
- `artifactregistry.googleapis.com`
- `iam.googleapis.com`

### Step 2 — Deploy

```bash
source set_env.sh
./scripts/deploy.sh
```

Or directly:

```bash
gcloud builds submit --config cloudbuild.yaml \
  --substitutions _REGION=us-central1,_AR_REPO=lawaier .
```

Cloud Build will:
1. Build backend Docker image (installs deps + pre-builds ChromaDB)
2. Deploy backend to Cloud Run
3. Capture backend URL
4. Build frontend Docker image (injects backend URL as `VITE_API_URL`)
5. Deploy frontend to Cloud Run
6. Print both URLs

### Step 3 — Access the portal

After deploy completes (~10-15 min), Cloud Build prints:

```
==================================================
  LAWAIER DEPLOYED
==================================================
  Backend:  https://lawaier-backend-xxxx-uc.a.run.app
  Frontend: https://lawaier-frontend-xxxx-uc.a.run.app
==================================================
```

Open the **Frontend URL** in your browser — that's the portal.

You can also find the URLs any time:

```bash
# Frontend URL
gcloud run services describe lawaier-frontend --region us-central1 \
  --format 'value(status.url)'

# Backend URL
gcloud run services describe lawaier-backend --region us-central1 \
  --format 'value(status.url)'
```

## Local Dev Tips

**Backend only** (if frontend already running):
```bash
cd backend
GOOGLE_CLOUD_PROJECT=your-project uvicorn main:app --reload --port 8000
```

**Frontend only** (pointing at Cloud Run backend):
```bash
cd frontend
VITE_API_URL=https://lawaier-backend-xxxx-uc.a.run.app npm run dev
```

**Re-build ChromaDB** (if you update `laws_data.json`):
```bash
cd backend
rm -rf lawaier_db/
python build_chromadb.py
```

**Verify RAG is working:**
```bash
cd backend
python query_test.py
```
